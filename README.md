#  Ma page web HTML & CSS

##  Description

Ce projet est une page web créée avec HTML et CSS. Et couplage VSC et Github avec ajout synchronisé.

L'objectif est de pratiquer les bases du développement web :
- créer une page HTML ;
- utiliser le CSS ;
- modifier les couleurs ;
- utiliser différentes polices ;
- mettre en forme un titre et des paragraphes.
- synchroniser VSC et Github

## Technologies utilisées

- HTML5
- CSS3
